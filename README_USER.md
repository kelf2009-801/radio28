# Рация 28 — что внутри APK

**Что работает прямо сейчас (без сервера):**
- Регистрация по позывному (RSA-ключ на телефоне)
- Поиск и вход в каналы
- Админка: запросы, approve/reject/kick/ban/mute, код-приглашение
- История разговоров
- Настройки

**Что заработает после поднятия сервера:**
- Голосовая рация (PTT) через LiveKit
- Push-уведомления о событиях (без Firebase)
- Видно «кто говорит», «кто онлайн» в реальном времени

## Что нужно сделать тебе (один раз)

1. **Купить VPS** (~$10-15/мес, карта МИР работает):
   - aeza.net / timeweb.ru / reg.ru — любой с Ubuntu 22.04
   - Тариф: 2 CPU / 4 GB RAM / 40 GB SSD
   - Регион: Сызрань/Урал/Казахстан (ближе — меньше задержка)

2. **Прислать мне:**
   - IP-адрес сервера
   - Логин/пароль root (или SSH-ключ)

3. **Я сам:**
   - Залью сервер (Docker-контейнеры: LiveKit + coturn + FastAPI)
   - Настрою, проверю
   - Соберу APK, который уже смотрит на твой сервер
   - Пришлю тебе файл — ставится на любой Android как обычное приложение

## После запуска

- Ты первым заходишь с позывным «Андрей» → автоматически становишься админом канала «Сызрань-28»
- Водители: ставят APK → ищут «Сызрань-28» → «Вступить» → ты подтверждаешь → они в эфире
- Никаких паролей, номеров телефонов, Google-аккаунтов

## Технические детали (для любопытных)

- Шифрование: DTLS-SRTP (WebRTC стандарт) + RSA-2048 для входа
- Задержка голоса: ~200-400 мс (как обычная рация)
- Трафик: ~24 кбит/сек на говорящего
- Сервер держит до 30 человек в канале без просадки
